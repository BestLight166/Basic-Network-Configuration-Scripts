# Network Automation Lab

This repository contains reusable Cisco configuration scripts designed to automate network deployment in lab environments.

## Features
- Base device configuration (hostname, interfaces, security)
- DHCP configuration and relay (ip helper)
- VLAN segmentation
- OSPF dynamic routing with authentication

## Purpose
These scripts are designed to be parameter-driven, allowing quick deployment by modifying IP addresses and network variables.

## Technologies
- Cisco IOS
- OSPF
- VLANs
- NAT
- STP
- DHCP
